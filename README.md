# Vanock

**Vanock is a technology-driven digital commerce platform combining books, community, and a rewards ecosystem.**

> **Current status:** Early-stage product and business development.

## Overview

Vanock is being developed as a platform where people can discover and purchase books while participating in a connected member and rewards ecosystem.

The current website uses existing web technologies, templates, scripts, and third-party components. This repository does **not** claim those components as original Vanock code. Instead, it documents the Vanock product concept, business model, user flow, rewards structure, and roadmap.

## Product

Vanock brings together:

- 📚 Books and digital commerce
- 👥 Member community
- 🔗 Referral and network relationships
- 🎁 Rewards
- ⚙️ Platform automation
- 📊 Future member and administrative tools

## Product Vision

The long-term vision is to develop Vanock into a scalable technology platform where commerce, knowledge, community, and rewards work together.

See [PRODUCT-VISION.md](PRODUCT-VISION.md).

## Business Model

Vanock generates revenue through book sales and allocates a defined portion of qualifying book profit to its rewards ecosystem.

See [BUSINESS-MODEL.md](BUSINESS-MODEL.md).

## User Flow

A simplified Vanock customer journey is:

**Discover * Register * Buy * Join * Refer * Build Network * Earn Rewards**

See [USER-FLOW.md](USER-FLOW.md).

## Rewards Model

The current model uses a 10-level network structure. The working example assumes:

- Average profit per qualifying book: **₦10,000**
- Rewards allocation: **40% of profit = ₦4,000**
- Vanock retained portion before other costs: **60% = ₦6,000**

See [REWARDS-MODEL.md](REWARDS-MODEL.md).

## Roadmap

Vanock is being developed progressively, with future work focused on improving the commerce experience, member management, rewards automation, analytics, and integrations.

See [ROADMAP.md](ROADMAP.md).
